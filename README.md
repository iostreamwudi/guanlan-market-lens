# 观澜 · Market Lens

面向A股研究者的证据工作台：回答“观察到什么、主要矛盾是什么、什么条件下需要重新审视判断”。不预测未来涨跌，不给出买卖、仓位或收益承诺。

- 产品：https://market-lens-ashare.freshanole18.chatgpt.site
- GitHub 源码：https://github.com/iostreamwudi/guanlan-market-lens
- [产品设计](docs/PRODUCT.md) · [AI使用与验证记录](docs/AI_RECORD.md) · [测试说明](docs/TESTING.md) · [演示脚本](docs/DEMO.md)

## 本地启动

需要 Node.js 22+，无第三方依赖、无需安装。

```sh
npm run dev
# http://localhost:4173
npm test
npm run build
npm run validate
```

`src/index.html` 为界面，`src/engine.js` 为纯计算与证据引擎，`src/server.js` 为数据适配、模型调用和HTTP接口。构建生成单文件 Cloudflare Worker ESM：`worker/index.js` → `dist/server/index.js`。Sites 托管配置见 `.openai/hosting.json`。

## 60秒上手

1. 打开产品，默认显示有醒目标记的构造演示，选择指数和5/20/60日区间，生成研判。
2. 点击 E1–E7 查看来源、时点、单位、公式与原始字段。
3. 将数据源切换为“公开指数日线（备选）”，生成真实指数历史观察；当日未收盘数据自动剔除。
4. 在“连接设置”输入扶摇 API Key，选择扶摇模式。无凭证明确失败，不自动伪造数据。
5. 可选输入 OpenAI API Key 及具有访问权限的模型名，继续研究。连接后才显示模型归纳；模型失败保留明确标注的规则结果。
6. 追问风格或风险，保存研究，导出 Markdown 或完整 JSON 证据包。

## 用户与产品选择

用户是需要解释盘面、做晨会/复盘的研究员和有研究经验的个人用户。核心页面围绕研究任务组织，先给观察状态与证据，再给缺失与复核条件。没有交易按钮、推荐股列表或预测胜率。

七维框架：行情结构、市场宽度、风格轮动、估值、流动性、情绪、重要事件。直接覆盖、代理与缺失分别呈现。成交量比不等于全市场资金流动性；实现波动率不等于投资者情绪；宽基指数比较不等于纯风格因子归因。

## AI角色与环境变量

模型只对受控工具返回的证据做“归纳/不确定”解释。数值计算、时点筛选、引用与边界校验由代码承担，模型不能调用任意URL、修改数据或输出交易建议。

采用 OpenAI Responses API，`store:false`，严格 JSON Schema，应用层检查引用ID、可追溯数字和越界措辞。事实数值仍由确定性计算产生。输出检查不是完备的事实核验或合规审查。

| 变量 | 是否必需 | 作用 |
|---|---|---|
| `FUYAO_API_KEY` | 否 | 服务端扶摇凭证 |
| `OPENAI_API_KEY` | 否 | 服务端 OpenAI 凭证 |
| `OPENAI_MODEL` | 否 | 默认 `gpt-4.1-mini`，可以配置有权限的模型 |

本地环境通过 shell 设置变量，本项目不自动读取 `.env`。也可使用页面会话设置：只在页面内存保存，刷新清除；经本站服务端向固定供应商转发，不进入报告、本地研究存储或代码仓库。模型调用会把研究问题和已取证字段发送到 OpenAI，并可能产生 API 费用。

**未配置模型时，产品可使用取数、计算、引用、追问焦点和导出主链路，但属于明确标记的规则研究模式，不宣称调用了大模型。实际模型在线调用未在无凭证环境下验收。**

## 数据来源与状态

1. **优先源：扶摇金融数据API。** 实现 `GET /api/a-share-index/prices/historical`，使用 `X-api-key`，单指数 `thscode`、`interval=1d`、毫秒级 `start/end`。检查HTTP状态与响应信封业务 `code`。官方文档：https://fuyao.aicubes.cn/docs/api-reference/a-share-index/ 。未获得有效凭证，因此真实授权调用未验收，协议与适配器通过构造响应测试。
2. **显式备选：腾讯公开指数日线。** `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`。无密钥，可请求沪深300、上证指数、创业板指、中证500历史日线。已实际验证返回及页面主链路；它是未承诺稳定性的公开接口，不代表授权合作，不保证未来可用性、及时性或生产再分发权利。正式商业使用应取得合法数据授权并接入优先源。
3. **构造演示。** `demoBars()` 确定性合成价格/成交量及构造宽度/估值。日期只是场景标签，按工作日生成，不冒充真实交易日历。所有演示数据均显示醒目标识。
4. **iFinD MCP 未连接。** 没有宣称取到资金、宏观、政策、新闻。真实模式中，市场宽度、估值、全市场资金、情绪和事件原文不足时显式缺失。

真实数据只在请求期间计算和返回，不在服务端落库或代码仓库中保存。用户主动保存的研究快照仅存于当前浏览器 localStorage，最多8条；可以清空或导出。

## 状态、指标与置信度

- N日区间变化需要N+1根完整日线；均线偏离使用最近20根；量比使用近5日对比此前20日。
- 波动率是日简单收益率样本标准差乘以√252，不是未来风险预测。
- 比较指数仅使用相同首末日期、完全对齐的同一日线序列。对齐失败不生成比较结论。
- 相对均线与区间变化阈值仅用于观察状态描述；宽基差3个百分点、样本宽度60%、持续3日等是未经预测回测的研究阈值。
- 置信度表示证据解释充分度，不是上涨概率。直接覆盖少于4维为低，达到4维为中；本版本不输出高。代理不计入覆盖。
- 最新完整日线距今超过7个自然日，暂停当前综合研判；节假日可能保守误报，需人工核验交易日历。

## 边界与未做事项

- 没有接入全市场宽度、点时成分、真实估值序列、资金/利率、涨跌停情绪与事件原文；不能据此做完整市场归因。
- 行业与历史阶段追问会说明所需证据，未实现行业排名、相似历史阶段检索或预测性回测。
- 研究计划由受控代码制定，模型承担证据归纳；未做开放式多轮自主工具选择，避免任意取数和幻觉。
- 非生产级合规系统：输入/输出的规则检查不能覆盖所有变体，仍需研究者审阅。模型引用存在并不自动保证语义被证据支持。
- 没有服务端账户、持仓画像、交易功能、定时监控、跨设备同步、长期审计库或分布式限流。
- 未提交演示视频（可选项），提供可直接照着操作的90秒脚本。
