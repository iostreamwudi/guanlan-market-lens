# 产品设计与题目验收映射

## 核心用户与任务

研究员选择指数、区间和研究问题，想理解已观察市场状态、主要矛盾与判断需要复核的条件。产品以证据链组织输出，支持继续研究风格、行业截面、风险或等长历史区间，不提供涨跌、仓位、买卖或收益承诺。

## 主链路

问题与范围 → 可选模型白名单规划/规则规划 → 指数日线 → 同日完整市场分页、涨跌停池、官方政策 → 按问题扩展行业/历史工具 → 完整性、时点、来源校验 → 确定性指标与事实 → 可选模型归纳及引用/边界检查 → 状态、缺失、条件 → 追问/保存/导出。

模型可以选择焦点与扩展工具，但不能绕过系统最低取证计划。主指数失败停止研判；单个补充工具失败单独降级，并在界面和日志保留失败数量及原因。跨日宽度不作为历史区间同日验证，维持低置信度。

## 新增的实际研究分支

- 行业：完整读取供应商板块列表、排序、搜索和展开原始字段；标明混合层级、重叠分类、同日截面口径。
- 历史：读取长日线，计算等长、不重叠历史窗口的变化、实现波动与均线偏离，按标准化特征距离排序；不计算后续收益。
- 风险：检查价格结构、个股参与、涨跌停分布与证据盲点，展示判断复核条件。
- 事件：从近30日官方索引筛选相关政策，读取成功后列示原文、发布日期和摘录；不宣称事件导致价格变化。

## 七维证据框架

行情结构、宽度、风格、估值、流动性、情绪、事件。已有来源字段、代理和缺失分别标记。全市场成交额仅代表成交活跃度，涨跌停仅代表盘面结构；维度覆盖不等于完整因果解释。估值统一口径、净资金与多日宽度仍缺失。
