# 观澜 · Market Lens

面向A股研究员的证据工作台：解释观察到的市场状态、主要矛盾、缺失证据和需要重新审视判断的条件。提供实际工具调用、可追溯原始字段、行业截面、历史区间对照和可选模型规划与归纳，不预测未来涨跌或提供仓位、买卖及收益承诺。

- **公开产品**：https://market-lens-ashare.freshanole18.chatgpt.site
- **公开源码**：https://github.com/iostreamwudi/guanlan-market-lens
- [产品设计](docs/PRODUCT.md) · [AI使用与验证记录](docs/AI_RECORD.md) · [测试说明](docs/TESTING.md) · [演示脚本](docs/DEMO.md)

## 一次完整研究

1. 选择指数及5/20/60日区间，默认取公开真实数据。
2. 系统读取指数与比较指数日线、完整市场快照、涨跌停池、近30日官方政策原文。失败的证据单独降级，主指数失败则停止研判。
3. 查看事实、归纳、不确定判断及每条证据ID，展开来源、时点、单位、公式与原始字段。
4. 追问行业：获取完整供应商行业板块截面，可查看和搜索全部有效板块；注意混合层级和板块重叠。
5. 追问历史：读取最长320根公开指数日线，比较同指数、不重叠等长区间的特征，不展示后续收益或预测胜率。
6. 保存到本浏览器，或导出Markdown报告与JSON完整证据包。

构造演示单独可选，所有样本标记为构造数据。真实源失败不会偷偷切换成演示。报告只能代表实际成功获取的维度，不能将理论上已实现的适配器当作当次有效证据。

## 用户与设计

用户是需要复盘、组织晨会材料、检验盘面解释的研究员和有研究经验的个人用户。页面围绕“问题—计划—工具—证据—解释—切换条件—继续研究”组织，没有推荐股列表、交易按钮或价格预测。

七个维度：行情结构、市场宽度、风格轮动、估值、流动性、情绪、重要事件。已有来源字段、代理和缺失分别显示；维度覆盖不等于完整市场归因。宽度缺失、与主指数跨交易日或主数据过期时维持低置信度。

## AI角色与连接

支持三类标准模型API：

| 供应商 | 接口 | 模型配置 |
|---|---|---|
| OpenAI | Responses API，严格JSON Schema，`store:false` | 默认 `gpt-4.1-mini`，须有账户权限 |
| DeepSeek | Chat Completions，JSON模式，应用层校验 | 默认 `deepseek-flash`，可以填写可用模型 |
| 火山方舟标准API | Chat Completions，JSON模式，应用层校验 | 填写已开通的Model ID或推理接入点ID；按标准API规则计费 |

模型负责两阶段工作：先从白名单选择研究焦点与扩展工具，工具执行完成后再对证据进行归纳。系统仍执行最低取证计划，禁止任意URL或新工具。指标和数值事实由代码产生，模型文本不得新增阿拉伯数字，每条归纳必须引用现有证据ID。模型计划失败或输出越界时明确降级，不伪造模型回复。

“连接设置”有独立的真实模型连接测试，会发送一个小型JSON请求并显示请求ID及验证时间；可能消耗少量Token。研究请求会把问题、证据摘要、少量行业/历史数据与政策摘录发送给选定供应商。凭证不包含在这些模型输入中。

**本次未完成标准模型业务API上线验证。用户提供的是Ark Coding Plan专用配置，官方限定用于编程工具，未把该凭证用于投研网页，也没有自动切换到会产生额外费用的标准API。需要可用于业务应用的标准API Key和已开通模型ID。** 官方说明：https://docs.volcengine.com/docs/ark/coding-plan-personal-plan-overview?lang=zh 。

已完成一次真实本地开发重测：模型规划、真实公开取数和归纳均成功，data_mode=public；归纳83.259秒，通过数据模式、引用与边界校验。请求ID及失败记录见 `docs/AI_RECORD.md`。本轮将每步等待上限调为90秒、归纳预算调为4096，并增加演示误标回归拦截。测试不保存用户凭证，也没有把Coding Plan加入生产业务供应商。


没有有效模型Key时，取数、计算、证据追溯和研究分支仍可操作，界面明确显示规则模式。

## 数据来源、口径与降级

| 来源 | 实现内容 | 当前验证边界 |
|---|---|---|
| 扶摇金融数据API（优先） | 指数历史、全市场行情快照分页、涨跌停股票池分页 | 文档及mock适配测试通过；无有效扶摇凭证，真实授权调用未验证 |
| 腾讯公开指数接口（备选） | 沪深300、上证指数、创业板指、中证500日线 | 实际取数与历史对照验证通过；无SLA |
| 东方财富公开接口（备选） | 全A股筛选集快照、行业板块、涨跌停股票池 | 完整分页探测曾成功；后续全市场/行业接口出现断连，必须以每次报告日志为准 |
| 中国政府网 | 近30日经济/产业相关政策索引与官方正文 | 实际读取原文验证通过；仅核实事件存在，不证明影响或因果 |
| iFinD MCP | 未接入 | 不宣称取得宏观、资金或资讯 |
| 构造演示 | 确定性合成价格、成交量及构造宽度、估值 | 日期只作场景标签，不冒充交易日历或真实历史 |

公开接口不是正式授权合作，不保证未来可用性或商业再分发许可；正式商用应取得相应数据授权。

市场快照按实际首页页长取得全部分页，总数变化、重复代码、页数超过预算或有效同日成交样本不足70%时停止聚合。上涨占比是“相对前收盘上涨的有效同日股票数/有效同日股票数”，不是高于均线比例。成交额使用同一筛选集原始成交额求和，仅说明成交活跃度，不等于净资金或宏观流动性。

涨跌停池按查询日期和证券代码校验，不以固定±10%阈值推断。行业分类包含供应商不同层级与重叠板块，不做互斥行业贡献，也不汇总可能重复的行业成交额。官方政策每条保留原文URL、发布日期和获取时间，原文读取失败不标记已核验。

公开补充数据仅在Worker进程内短时缓存120秒，保持原始时点；不同交易日证据不混作同日验证。金融授权数据与用户凭证不参与共享缓存。

## 环境变量与凭证

访客默认自带Key，仅保存在当前页面内存，刷新清除；不进入localStorage研究记录、导出报告或仓库。

| 变量 | 作用 |
|---|---|
| `FUYAO_API_KEY` | 可选部署者扶摇凭证 |
| `MODEL_PROVIDER` | `openai` / `deepseek` / `ark` |
| `MODEL_API_KEY` | 可选部署者标准模型凭证 |
| `MODEL_NAME` | 对应供应商的已开通模型ID |
| `OPENAI_API_KEY` / `OPENAI_MODEL` | 兼容旧版OpenAI配置 |
| `RESEARCH_ACCESS_TOKEN` | 使用任何部署者Key的必需口令；不提供或不匹配时，公开访客不能调用部署者凭证 |

本地通过shell设置变量，不自动读取 `.env`。在连接设置的高级区域输入部署者口令才能使用服务端Key；独立模型连接测试使用访客自带Key。不要将真实Key提交仓库。公开部署未配置共享模型或金融数据Key。

## 指标与观察规则

- N日变化需要N+1根完整日线；均线使用最近20根；量比使用近5日对比此前20日。
- 实现波动率是日简单收益率样本标准差乘√252，不是未来波动预测。
- 比较指数日线逐日对齐，对齐失败不生成区间表现差。
- 当日未收盘日线剔除；最新完整日线距今超过7个自然日暂停当前综合判断，节假日可能保守误报，需人工核验交易日历。
- 研究阈值未经预测回测。条件展示可评估性和缺失，不等于未来行情触发器。
- 置信度是解释充分程度；最多输出中，宽度缺失或跨日时保持低，绝不是上涨概率。

## 文件结构

- `src/engine.js`：基本指标、状态、边界与引用校验。
- `src/supplement.js`：完整分页、宽度/成交、涨跌停、行业、政策与历史对照。
- `src/model.js`：固定供应商端点、JSON输出、白名单规划、真实连接测试。
- `src/server.js`：研究主链路、权限与HTTP接口。
- `src/index.html` / `src/enhancements.js`：响应式界面与深度研究分支。
- `tests/`：50项自动化测试；`docs/`：提交说明材料。

## 已知边界和未做事项

1. 真实模型业务调用和扶摇授权调用仍需合适凭证，mock不代替真实验收。
2. 公开全市场/行业接口存在间歇性断连，可能导致宽度、成交额和行业证据缺失。当前覆盖以实际报告为准。
3. 统一口径估值、净资金、利率、多日个股均线宽度、点时成分与严格交易日历仍未完善。
4. 历史对照不是预测回测；行业截面不是所选指数成分的行业贡献。
5. 正则边界、JSON与有效引用检查不能完成全面金融合规或语义事实核验，研究者仍需审阅。
6. 没有交易、持仓画像、服务端研究数据库、跨设备同步、分布式限流与生产SLA。
7. 保存快照仅当前浏览器，最多8条，存储不足时提示导出；没有提交可选演示视频。

## v1.2：官方事件备用取证与来源状态

中国政府网原文不可用时，独立读取上海证券交易所官方热点动态索引，核验近30日原文标题、日期、正文和同源链接；交易所活动不当作宏观政策或已发生的资金流。界面提供本次取证状态，展示原文尝试、失败与备用来源。公共快照成功结果进程内缓存两分钟，官方事件十五分钟；报告保留原取证时点和缓存年龄，失败不缓存、用户授权数据不写入该公共缓存。

官方原文读取只允许中国政府网和上交所固定HTTPS源，最多跟随两次同源重定向。全市场公开接口仍可能失败，本轮未将不完整分页或无日期报价当作全市场证据。新增备用事件源的真实本地测试取得两条原文，部署后的有效覆盖另见提交包线上验收记录。
