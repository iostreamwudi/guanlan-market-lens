# 90秒产品演示脚本（非视频）

| 时间 | 操作与讲解 |
|---|---|
| 0–12秒 | 打开观澜，说明服务研究员理解观察状态，不预测涨跌。指出当前是构造演示。 |
| 12–30秒 | 切换公开指数数据、沪深300、20日，生成研判。展示截至完整日线的时点和低置信度，解释缺失维度。 |
| 30–45秒 | 点击E1证据，展示原始首末价格、来源端点与公式，区分事实和归纳。 |
| 45–60秒 | 追问“哪些风险变量会让判断失效”，展示重新取数、状态切换条件与缺失证据。 |
| 60–75秒 | 切换构造演示的“数据缺失”或“接口失败”，展示降级或停止研判。 |
| 75–90秒 | 输入预测/仓位请求，展示边界拦截；导出报告，说明JSON含完整证据链。 |

如果已配置有效模型凭证，可在45–60秒展示模型归纳状态与引用校验。没有配置时应诚实讲解“当前是规则研究模式，模型适配器已实现但真实调用未验收”，不要声称AI已实时分析。
