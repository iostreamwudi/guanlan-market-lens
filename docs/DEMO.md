# 90秒产品演示脚本（未制作可选视频）

| 时间 | 操作与讲解 |
|---|---|
| 0–15秒 | 打开公开产品，选择沪深300和20日区间；默认实际公开数据取数。 |
| 15–30秒 | 展示事实、归纳、不确定判断与缺失维度；说明覆盖以本次成功取证为准。 |
| 30–45秒 | 展开指数、涨跌停和政策证据，核对原始字段、时点、单位与官方原文。 |
| 45–60秒 | 追问历史阶段，展示等长、不重叠区间、特征距离及“不推演未来”限制。 |
| 60–75秒 | 追问行业：数据成功时搜索板块；失败时展示失败记录，不能冒充正常排名。 |
| 75–90秒 | 输入预测/仓位问题展示拦截；保存或导出完整证据报告。 |

如果有标准模型API凭证，可先在连接设置验证，再展示“模型规划—白名单工具—证据归纳”。没有有效凭证就明确讲解规则模式，不能声称已实时调用大模型。Coding Plan专用Key不作为本业务网页凭证。
